# Why a workflow failed

## Overview

Open **Workflows → Executions**, select the failed run, and inspect the first failed step and its error message.

## Recommended steps

Common causes include expired credentials, invalid input, upstream API errors, permission changes, and execution timeouts. Compare the failed run with a successful execution and inspect sanitized input/output data.

## Additional guidance

Resolve the underlying issue before retrying. Avoid exposing secrets or customer data in support screenshots.

## Contact support

If you still need help, provide the article ID **KB-WF-001**, a description of the problem, relevant UTC timestamps, and sanitized request or execution IDs. Never share passwords, access tokens, or payment-card details.
