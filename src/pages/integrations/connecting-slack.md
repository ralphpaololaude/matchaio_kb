# Connecting Slack

## Overview

Open **Integrations → Slack → Connect**, select the target Slack workspace, and approve the requested permissions.

## Recommended steps

Choose a destination channel for notifications and send a test message. Ensure the Matcha.io app is a member of private channels before selecting them.

## Additional guidance

If notifications stop, reconnect the workspace and check channel membership and Matcha.io execution logs.

## Contact support

If you still need help, provide the article ID **KB-INT-002**, a description of the problem, relevant UTC timestamps, and sanitized request or execution IDs. Never share passwords, access tokens, or payment-card details.
