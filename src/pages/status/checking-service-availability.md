# Checking service availability

## Overview

Visit `https://status.matcha.io.example` (illustrative URL, not a live service) to view the current status of the Matcha.io API, dashboard, and integrations.

## Recommended steps

Check active incidents and scheduled maintenance notices. Subscribe to updates if your organization has enabled notifications.

## Additional guidance

If no incident is posted but you experience errors, capture the affected component, UTC timestamps, and request or execution IDs before contacting support.

## Contact support

If you still need help, provide the article ID **KB-STATUS-001**, a description of the problem, relevant UTC timestamps, and sanitized request or execution IDs. Never share passwords, access tokens, or payment-card details.
