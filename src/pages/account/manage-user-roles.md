# Managing user roles

Matcha.io administrators can manage the roles assigned to other Matcha.io users. Each role as defined permissions, which allow or deny access to different sets of features in Matcha.io.

## Definitions

- **Permissions**: Permissions provide your users with appropriate levels of access to Matcha.io features based on the work they need to do.
- **Roles**: Roles are sets of permissions that can be assigned to users. Users can have different roles in separate organizational accounts. 
- **Users**: Users with the Administrator role can add, edit, and delete other users and manage the actions users can perform by assigning one or more roles.

## User management

### Adding a user

1. Log in to the Matcha.io Portal using your administrator account.

2. On the navigation bar, click **Admin**, then select the *User Management* tab.

3. Select *Users*, then click **Invite**.

4. In the Invite User dialog, enter the email address of the user.

5. Select the user roles you want to assign to the user.

6. Click **Invite**.

After you add the user, they will receive a confirmation email with an account activation link.

### Changing user roles

To edit the roles and permissions of a user:

1. On the navigation bar, click **Admin**, then select the *User Management* tab.

2. Select *Users*.

3. Find and select the user whose roles you need to change.

4. Click **Actions**, then click **Edit**.

5. Update the roles and permission as required, then click **Save**.

### Delete a user

1. On the navigation bar, click **Admin**, then select the *User Management* tab.

2. Select *Users*.

3. Find and select the user to be deleted.

4. Click **Actions**, then click **Delete**.

5. Confirm the email address of the user to be deleted, then click **Confirm**.
