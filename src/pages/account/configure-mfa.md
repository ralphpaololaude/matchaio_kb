# Configure Two-Factor Authentication (2FA)

Two-Factor Authentication provides an additional layer of account security by requiring users to verify their identity using two or more distinct types of evidence (factors) before accesing the account.

To configure MFA:

1. Sign in to your Matcha.io account, then go to *Settings* > *Profile* > *Security*.

2. Click *Enable 2FA*.

3. Scan the QR code using your preferred authentication app.
   
   Suggested apps: Google Authenticator, Microsoft Authenticator, Bitwarden

4. Follow the instructions in the app.

5. Enter the code generated the authentication app.
