# Understanding usage limits

## Overview

Open **Settings → Usage** to review monthly workflow executions, API requests, and integration activity.

## Recommended steps

For this fictional product, the Starter plan includes **10,000 workflow executions per month**, while the Pro plan includes **100,000**. The billing page displays your current plan and effective limits.

## Additional guidance

Usage resets at the start of the workspace billing cycle. If you approach a limit, reduce unnecessary runs or review upgrade options with a billing administrator.
